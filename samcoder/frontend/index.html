⚡ Hemat Token

💡 Token itu apa? Token = "bahan bakar" AI. Semakin dalam Coder berpikir, semakin banyak token terpakai = semakin besar biaya. Tab ini bantu kamu kendalikan biaya.

🧠 Level berpikir: Off/Low = cepat & murah (untuk tugas ringan, chat biasa) · Medium = seimbang (rekomendasi harian) · High/Max = sangat dalam & mahal (hanya untuk debugging sulit).

💰 Perbandingan biaya: DeepSeek flash = $0.14/1M token input · Level High bisa pakai 10× lebih banyak token daripada Off. Pilih level sesuai kebutuhan.

⏰ Jadwal Agent

📖 Apa ini? Jadwal = suruh Coder bekerja otomatis tanpa kamu pegang HP/laptop. Contoh: "setiap pagi jam 7, cek harga emas dan tulis ringkasannya".

🕐 Format jam (paling gampang): 0 7 * * * = jam 7 pagi tiap hari · 30 18 * * * = jam 6:30 sore tiap hari · 0 9 * * 1 = jam 9 pagi tiap Senin.

🧩 Cara baca: menit jam tanggal bulan hari — bintang (*) = semua. Contoh 0 2 * * * = tiap hari jam 2 pagi.

⚙️ Faktor Jual Credit

Pengaturan model bisnis: potongan credit = cost aktual × faktor jual. Semakin tinggi faktor, semakin besar untung Papi. Rugi ZERO di semua model.

📊 Simulasi Profit (per 1 juta token, mix 70% input / 30% output)

Kurs: $1 = Rp16.000 · margin konstan = (faktor−1)/faktor × 100%

memuat...
📌 CATATAN MODEL BISNIS (jangan lupa!)

• Prinsip: "Dia pakai apa, kita hitung apa." Pemakaian cost aktual dihitung dari sistem — model murah potong dikit, model mahal potong banyak, kombinasi dihitung sesuai porsi.
• 1 credit = Rp1. User beli saldo Rupiah (credit). Pemakaian dipotong = cost × faktor jual.
• Margin: faktor 6× = untung 83,3% (profit 5× cost). Faktor 8× = 87,5%. Faktor 10× = 90%.
• Contoh profit 6×: flash 1jt token → cost Rp2.912 → potong Rp17.472 → profit Rp14.560. gpt-4o 1jt → cost Rp76.000 → potong Rp456.000 → profit Rp380.000.
• Skenario 1 user aktif/hari: flash 2jt + pro 500rb + gpt-4o 200rb → cost Rp25.548 → potong Rp153.288 → profit Rp127.740/hari.
• Proyeksi bulanan: 1 user = ±Rp3,8jt · 5 user = ±Rp19jt · 10 user = ±Rp38jt.
• Harga jual: Rp10.000 credit ≈ 572rb token flash · Rp20.000 ≈ 1,14jt flash · Rp100.000 ≈ 5,7jt flash (atau ±22rb/219rb token gpt-4o).
• Tarif model terbaru harus dipantau — kalau harga provider berubah, update tabel tarif biar potongan tetap akurat.
